# Contributing to FocusLoop

First off, thank you for considering contributing to FocusLoop! It's people like you that make FocusLoop such a great tool.

## Code of Conduct

This project and everyone participating in it is governed by the [FocusLoop Code of Conduct](CODE_OF_CONDUCT.md). By participating, you are expected to uphold this code.

## How Can I Contribute?

### Reporting Bugs

- **Check if the bug has already been reported** by searching on GitHub under [Issues](https://github.com/Ata-Ul-Hai/FocusLoop/issues).
- If you can't find an open issue addressing the problem, [open a new one](https://github.com/Ata-Ul-Hai/FocusLoop/issues/new).
- Include a **clear title and description**, as much relevant information as possible, and a **code sample** or an **executable test case** demonstrating the expected behavior that is not occurring.

### Suggesting Enhancements

- Check if there's already a similar suggestion.
- Open a new issue with a clear title and description of the feature you'd like to see.

### Pull Requests

1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. If you've changed APIs, update the documentation.
4. Ensure the test suite passes.
5. Make sure your code lints.
6. Issue that pull request!

## Styleguide

### JavaScript Styleguide

- We use standard ES6+ syntax.
- We follow the Prettier configuration included in the project.
- Aim for functional components and clean service separation.
